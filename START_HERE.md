# Start here
This is a learning/reference project. Do not submit it unchanged. Understand the code, make your own justified choices and observations, and perform actual execution on BITS Virtual Lab.

1. Extract ZIP and open the bits-ml-assignment-2 folder inside BITS Virtual Lab.
2. Use the available VS Code/JupyterLab/editor; check Python 3.12 and terminal access.
3. Read README sections a-d and data/SOURCE.md. Inspect the target remapping in prepare_data.py.
4. Install dependencies: python -m pip install -r requirements.txt
5. Read train_models.py and evaluation.py. Run: python train_models.py
6. Validate artifacts and result consistency: python verify_project.py
7. Read results/metrics.csv, update the README comparison, and write your own five observations and winner rationale. Never invent metrics or claims of general superiority.
8. Capture one genuine lab screenshot after successful execution. No screenshot is included here.
9. Run: python -m streamlit run app.py
10. Upload test_data.csv and inspect all models, six metrics and confusion matrix/report. Customize the presentation yourself. Do not retrain on uploaded test data.
11. Create a dedicated repository under ckchauhan89. Add your adapted work and genuine commits. Update the README repository URL.
12. Deploy that repo on Streamlit Community Cloud, branch main, entry point app.py, Python 3.12.
13. Verify both links in a private browser window and update the README live URL.
14. Make one PDF: GitHub link, live app link, lab screenshot, complete required README content, in that order.
15. Submit through the BITS portal before 8 November 2026 23:59 (confirm portal timezone). Do not leave a draft.

Assignment does not require from-scratch classifiers, a specific IDE, Docker, AWS, CI/CD, or a new GitHub account.
The included models were trained in a reference environment; rerun in BITS Lab. This ZIP is not a finished submission PDF.
